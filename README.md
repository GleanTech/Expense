# 收支记录 · Expense Tracker

离线优先的单文件 HTML 记账与报销管理工具。全部数据保存在浏览器本机的 IndexedDB 中，不上传、不联网、不依赖 CDN；通过 JSON 文件完成备份、迁移与交接。

## 项目特点

| 特性 | 说明 |
| --- | --- |
| 单文件应用 | `index.html` 内联全部 CSS、JavaScript 与三语文案，可直接双击打开 |
| 数据本地化 | 数据写入浏览器 IndexedDB，不发送到任何服务器；页面明确提示「数据仅存本机，不上传」 |
| 离线可用 | 托管版配合 `sw.js` 缓存应用外壳，首次打开后断网可用；`file://` 环境自动跳过注册 |
| 多周期适配 | 标准月度周期、自定义每月起始日、单次出差起止日期三种模式 |
| 公务 / 私人分离 | 每笔记录独立标记「商务 / 私人 / 家庭」与「收入 / 支出」，可报销记录单独追踪公司、进度 |
| 多币种 | 默认 RMB (CNY) / EUR / NTD (TWD) / USD，字典可扩展 |
| 二级联动字典 | 支付方式、分类标记、报销公司支持一级 / 二级菜单，可增删改、拖拉排序 |
| 完整交接 | 全量 JSON 快照（含设置、字典、软删除）与独立字典档；FNV-1a 校验和防止篡改与损坏 |
| 三语界面 | 简体中文 / 繁體中文 / English，仅切换界面文字，不改动用户录入内容 |
| 归档与 PIN | 锁定归档冻结编辑；可选 4–6 位 PIN 仅防误开 |
| 数据健康度 | 显示最后导出时间与未导出笔数，超阈值提示备份 |

## 运行与部署

### 推荐：托管 + 添加到主屏幕（iPhone / iPad）

1. 将 `index.html` 与 `sw.js` 上传到 GitHub 仓库，开启 GitHub Pages。
2. 用 Safari 打开 Pages 地址，点「分享」→「添加到主屏幕」。
3. 从主屏幕图标启动，行为接近原生 App；首次联网打开后即可离线使用。

> iOS 的文件 App 直接点击 HTML 不可靠：Quick Look 只预览、不执行 JavaScript。请用托管 URL 打开。

### PC 本地使用

双击 `index.html`（`file://`）。天然离线，数据存于该浏览器的 IndexedDB。`file://` 下不注册 Service Worker，建议定期用「导出账本数据」备份。

### 首次设置

三步向导：

1. **选择语言**：简体中文 / 繁體中文 / English。
2. **档案设置**：填写账本名称；可选选择出差计划 / 核准文件（仅存文件名）。
3. **周期设置**：选择记账方式与对应参数，完成后进入启动确认页。

向导中也可直接选择「导入账本数据」，按 JSON 中的状态恢复。

## 记账功能

| 字段 | 说明 |
| --- | --- |
| 收支类别 | 支出 / 收入 |
| 用途类别 | 商务 / 私人 / 家庭（独立维度，不是收支的子项） |
| 金额 | 最多两位小数；内部按「分」存整数，显示时除以 100 |
| 币别 | 下拉选择 + 字典编辑；默认 RMB / EUR / NTD / USD |
| 支付方式 | 二级联动下拉：一级（APP / 信用卡 / 现金 / 转账）+ 二级（支付宝、VISA1 等） |
| 分类标记 | 二级联动下拉：一级（交通 / 餐饮 / 住宿 / 通信 / 私人 / 家庭 / 办公室 / 未分类）+ 二级子项 |
| 报销标示 | 可报销 / 不报销；可报销时展开公司下拉 |
| 报销进度 | 未提交 / 已提交 / 已到账；仅可报销记录有业务意义 |
| 简易记录 | 单行，最多 60 字 |
| 复杂叙述 | 自拉伸多行，最多 2000 字 |
| 对应发票文件 | 每笔一张，仅保存文件名与相对路径，不上传文件内容 |
| 记账时间 | 日期 + 24 小时制时间，保存为带设备时区偏移的 ISO 时间；显示为 `YYYY/MM/DD HH:mm (UTC±HH:mm)` |

- 一级联动切换时，二级自动带出该一级的第一个子项，避免残留错误组合。
- 快速记账预填：支出 / 商务 / RMB / APP / 未分类 / 可报销 / 未提交。
- 保存时金额格式校验；可报销但未填公司会阻断保存。
- 字典被修改后，记录中的旧值会标红提示「需重新分类」，不会被静默改写。

## 周期管理

三种记账方式：

| 方式 | 周期计算 |
| --- | --- |
| 标准周期 | 指定年份 + 月份，起止为该月 1 日至月末 |
| 自定义周期 | 指定每月起始日（如 26 日），周期为当月 26 日至次月 25 日 |
| 单次出差 | 显式指定出差起始日与结束日 |

- 每条记录带有 `periodRef`（所属账本 ID、周期方式、起止日期），**周期归属与发生时间相互独立**。
- 切换周期时计算发生在新周期外的记录笔数并提示；记录不会被移动、隐藏或删除。
- 管理页按归属分组显示：**周期前 · 提前采购 / 预付**、**周期内**、**周期后 · 延后 / 补记**、**其他周期**；筛选可切「当前周期 / 全部周期」。
- 导出报表文件名包含周期起止日期，格式为 `账本名_起始日_结束日.csv / .pdf`。

## 报销管理

- 可报销记录需选择报销公司（默认四家：上海公司 / 德国公司 / 广州公司 / 台湾公司，可在字典中修改）。
- 进度三态：未提交 → 已提交 → 已到账；列表以标签显示，筛选、统计、CSV、PDF 均包含该字段。
- 详情提供「复制为新记录」：复制全部业务字段，生成新 ID 与创建时间，发生时间重置为当前（可改），发票字段清空，进度重置为未提交。
- 多选批量操作：批量改报销公司（下拉 + 自定义输入）、批量改进度、批量软删除；均二次确认并显示影响笔数。

## 发票管理

- 通过文件选择器单张选择发票（PDF / JPG / JPEG / PNG / BMP），只记录文件名与相对路径。
- 「选择发票文件夹」可一次性选取本地文件夹建立清单；「校验发票链接」重新选择文件夹比对，改名或移走的发票在列表中红字显示「失效」。
- 保存时检测发票文件重名：命中时显示已被哪笔记录占用，可选择「仍要保存」。软删除记录不参与重名检测。
- 不上传发票内容，不生成缩略图；校验仅比对文件名与相对路径。

## 字典管理

五类字典均可从表单上的「编辑」按钮进入：币种、支付方式、分类标记、报销标示、报销进度。

- 支持新增、重命名、删除；内置「未分类」不可删除。
- 支付方式 / 分类 / 报销标示支持一级 + 二级结构；二级项可用拖拉把手排序，也可用 ↑ / ↓ 按钮移动。
- 删除被引用的字典项时，引用它的记录迁移到「未分类」并二次确认。
- 字典种子固定简体中文；切换界面语言只改显示标签，不翻译用户数据。
- **独立字典档**：可单独「导出字典档 / 导入字典档」，用于多设备统一分类。导入前显示预览（项数、导出时间、校验和）；导入后以字典档为准，记录中已被修改或删除的分类不会被改写，而是标红提示需重新分类。

## 管理、筛选与报表

**筛选**：关键字（简易记录 / 复杂叙述 / 分类 / 发票名）、一级分类、币别、报销公司、报销进度、当前周期 / 全部周期。

**统计**：按币种展示收入合计、支出合计、净额；空态占位。软删除记录不计入统计。

**软删除**：删除记录写入 `deletedAt` 并移出主列表；软删除区可恢复或彻底删除（二次确认）。超过 30 天的软删除记录显示备份 / 清理提醒，系统不会自动删除。

**CSV**：UTF-8 BOM，含日期、时间、类型、用途、金额、币别、支付、分类、报销、公司、进度、简易记录、复杂叙述、发票；末尾附加独立的软删除区块。

**PDF**：通过浏览器打印「另存为 PDF」，白底打印样式，含标题、账本名、周期、筛选条件、表格、按币种统计；可勾选「按报销公司分组」，仅对可报销记录分段并给出各币种小计；末尾同样附软删除区块。

## 数据管理

| 操作 | 规则 |
| --- | --- |
| 导出账本数据 | 下载完整 JSON 快照；**唯一会更新「最后导出时间」与未导出计数基准的操作** |
| 复制账本数据 | 复制同样内容的 JSON 到剪贴板；不更新健康度基准 |
| 导入账本数据 | 仅空库可用：有数据 → 先导出 → 初始化清空 → 再导入 |
| 导入校验 | 校验 `schemaVersion`、结构、FNV-1a 校验和；失败直接阻断并给出原因 |
| 导入预览 | 校验通过后显示账本名、周期、记录数、字典项数、界面语言、锁定与 PIN 状态、校验和、导出时间；必须确认才覆盖 |
| 导入语义 | 快照整体替换：元信息、字典、记录（含软删除）全部按文件恢复 |
| 初始化数据 | 提示先导出 → 二次确认 → 清空并回到首次设置 |
| 结束 / 完成记账周期 | 二次确认 → 锁定数据库 → 导出 JSON 备份 → 初始化，进入下一周期；锁定态仍可执行 |
| 数据健康度 | 最后导出时间 + 未导出笔数（含软删除）；≥7 天或 ≥20 笔时提示备份 |
| 字典档 | 单独导出 / 导入字典 JSON，便于多端统一分类 |

## 锁定、PIN 与权限

锁定归档用于周期结束后冻结数据：

| 操作 | 开放状态 | 锁定状态 |
| --- | --- | --- |
| 查看记录、统计、软删除区、健康度 | 允许 | 允许 |
| 导出 JSON / 复制 JSON / CSV / PDF | 允许 | 允许 |
| 切换界面语言 | 允许 | 允许 |
| 新增 / 修改 / 删除 / 复制 / 批量操作 | 允许 | 禁止 |
| 修改报销进度、字典、周期与档案设置 | 允许 | 禁止 |
| 导入、初始化 | 允许（导入仅空库） | 禁止 |
| 解锁 | — | 二次确认，若启用 PIN 需输入 PIN |

- PIN 默认关闭。启用需二次确认 + 4–6 位数字；关闭需输入当前 PIN。
- PIN 以 `FNV-1a(salt + pin)` 存储，**仅防误开，不是安全加密**。
- 忘记 PIN：二次确认 → 强制导出当前状态 → 初始化清空 → 导入备份恢复。

## 多语言与主题

- 界面语言：简体中文（`zh-CN`）、繁體中文（`zh-TW`）、English（`en`）；切换即时重绘并写入 `lang` 属性与持久化设置。
- 锁定状态下仍可切换语言；用户录入的账本名、备注、分类值原样保留，不翻译。
- 主题：跟随系统 / 浅色 / 深色。浅色为白底 + 清淡莫兰迪绿主色（`#7C9A85`），深色为低对比深绿灰。

## 离线缓存 sw.js

- `sw.js` 缓存应用外壳（`./` 与 `./index.html`），缓存名 `expense-tracker-v2`；采用「缓存优先 + 网络回填」策略。
- 默认注册同目录 `./sw.js`；也可在「数据管理」中设置自定义 `sw.js` 网络地址。
- 自定义地址必须是**与页面同源的公网 HTTPS 地址**。跨源地址会被浏览器拒绝；`file://` 与 `http://` 下自动跳过注册。

## 数据格式

| Object store | 主键 | 索引 |
| --- | --- | --- |
| `meta` | `key` | — |

| `records` | `id` | `occurredAt`、`currency`、`categoryL1`、`reimbursementEntity`、`reimbursementStatus`、`deletedAt`、`updatedAt` |

```jsonc
{
  "schemaVersion": 1,
```

## 安全与隐私

- 无后端、无遥测、无 CDN；GitHub 仅托管静态文件。
- 发票只保存文件名与相对路径，文件本身不会被读取上传。
- PIN 是前端哈希，仅防误开，不能抵御有意访问设备者。
- 数据不随 HTML 文件复制：换设备、换浏览器、清理站点数据前请先导出 JSON。
- Safari 可能清理长期不访问的站点存储；主屏幕图标 + 定期导出可降低风险。

## 兼容性与限制

- Safari iOS 16+（建议主屏幕模式）、Chrome / Edge 桌面版。
- 响应式布局，适配 320 / 768 / 1440px；按钮最小 44px，支持键盘操作与读屏标签。
- 面向千笔级记录；批量写入使用 IndexedDB 事务。
- 不支持多端自动同步（已预留 `deviceId` / `updatedAt` / `deletedAt`，本版不实现）。
- 发票文件必须仍在原路径才能通过链接校验；应用不打包发票原件。

## 常见问题

**Q：导入按钮是灰的？**
A：数据库中已有数据。先「导出账本数据」，再「初始化数据」，然后导入。校验通过后会先显示预览，确认才覆盖。

**Q：切换周期后记录不见了？**
A：记录仍在。管理页默认显示当前周期归属；把筛选切到「全部周期」，可在「周期前 / 周期后 / 其他周期」分组中找到。

**Q：导出的 JSON 导入时提示校验失败？**
A：文件被修改或下载不完整。请使用本应用导出的原始文件；不要在文本编辑器中手动改动 `exportedAt`、`checksum` 或记录内容。

**Q：健康度的「未导出笔数」为什么复制 JSON 后没变？**
A：只有「导出账本数据」（下载）会更新基准；「复制账本数据」不改变基线，避免误判。

**Q：iPhone 上打开本地 HTML 没反应？**
A：iOS 文件 App 的 Quick Look 不执行 JavaScript。请用 GitHub Pages 等托管 URL，在 Safari 中打开并添加到主屏幕。

**Q：自定义 sw.js 地址为什么注册失败？**
A：必须与页面同源且为公网 HTTPS。`file://`、`http://`、localhost、私有 IP、跨源地址都会被拒绝。
